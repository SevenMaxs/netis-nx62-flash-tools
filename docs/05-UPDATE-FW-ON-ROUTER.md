# 🚀 Обновление прошивки на роутере (On-Router)

В этой инструкции описан процесс **обновления загрузчика и прошивки OpenWRT** непосредственно **на самом роутере** Netis NX62 / Netcore N60 Pro.

> 💡 **Примечание:** Этот способ используется, когда роутер **уже работает под управлением OpenWRT** и нужно обновить загрузчик (FIP/BL2) и прошивку без использования ПК.

## 📋 Предварительные требования

- ✅ Роутер уже работает под управлением **OpenWRT 24.x, 25.x или SNAPSHOT**
- ✅ **Доступ в интернет** с роутера (для скачивания образов)
- ✅ **~50 МБ** свободного места в `/tmp`
- ✅ Права **root** на роутере

## 📦 Что делает скрипт

Скрипт `netis-nx62-update-fw-on-router.sh` автоматически выполняет:

1. **Автоопределение актуальной версии OpenWRT** — находит последние 5 версий с поддержкой `mediatek/filogic` и предлагает выбрать
2. **Проверку прав root** и модели устройства
3. **Проверку свободного места** в `/tmp`
4. **Скачивание образов OpenWRT** (FIP, preloader, sysupgrade)
5. **Установку kmod-mtd-rw** из репозитория (apk или opkg)
6. **Запись загрузчика** в разделы FIP и BL2
7. **Установку постоянной прошивки** через `sysupgrade`

> 💡 **Важно:** В отличие от прошивки с ПК, этот скрипт **не требует форматирования UBI** — `sysupgrade` делает это автоматически.

---

## 🚀 Быстрый запуск

Самый простой способ — запустить скрипт одной командой с вашего ПК:

```bash
# С автоопределением версии (интерактивный выбор из топ-5)
ssh root@192.168.1.1 "wget -qO- https://raw.githubusercontent.com/SevenMaxs/netis-nx62-flash-tools/main/flash/netis-nx62-update-fw-on-router.sh | sh"

# С указанием конкретной версии
ssh root@192.168.1.1 "wget -qO- https://raw.githubusercontent.com/SevenMaxs/netis-nx62-flash-tools/main/flash/netis-nx62-update-fw-on-router.sh | sh -s -- -v 24.10.0"

# Неинтерактивный режим + конкретная версия
ssh root@192.168.1.1 "wget -qO- https://raw.githubusercontent.com/SevenMaxs/netis-nx62-flash-tools/main/flash/netis-nx62-update-fw-on-router.sh | sh -s -- -y -v 25.12.5"
```

> 💡 **Совет:** Если не указывать версию (`-v`), скрипт сам найдёт последние 5 доступных версий и предложит выбрать.

> ⚠️ **Важно:** При запуске через pipe скрипт читает ввод пользователя напрямую из терминала (`/dev/tty`), поэтому подтверждение должно работать корректно.

## 🚀 Пошаговая инструкция

### Альтернативный способ: ручное скачивание и запуск

Если вы предпочитаете сначала скачать скрипт, а затем запустить:

```bash
# Скачивание скрипта на роутер
wget -O /tmp/netis-nx62-update-fw-on-router.sh \
  https://raw.githubusercontent.com/SevenMaxs/netis-nx62-flash-tools/main/flash/netis-nx62-update-fw-on-router.sh

chmod +x /tmp/netis-nx62-update-fw-on-router.sh

# Запуск с автоопределением версии
sh /tmp/netis-nx62-update-fw-on-router.sh

# Запуск с конкретной версией
sh /tmp/netis-nx62-update-fw-on-router.sh -v 24.10.0
```

Или скопируйте с ПК:

```bash
scp netis-nx62-update-fw-on-router.sh root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sh /tmp/netis-nx62-update-fw-on-router.sh"
```

## 🔄 Детальное описание этапов

### Этап 1: Подготовка
- Проверка прав root
- Проверка модели устройства (из `/etc/board.json`)
- Проверка свободного места (требуется ~50 МБ)

### Этап 2: Определение версии
- Если указан аргумент `-v VERSION` — используется указанная версия
- Иначе скрипт сканирует `https://downloads.openwrt.org/releases/`, находит все стабильные версии и проверяет наличие сборок для `mediatek/filogic`
- Выводит топ-5 доступных версий и предлагает выбрать
- При отсутствии интернета или ошибке автоопределения — fallback на версию по умолчанию (25.12.5)

### Этап 3: Скачивание образов
Скрипт загружает файлы с динамически сформированными именами:
- **bl31-uboot.fip** — загрузчик U-Boot (записывается в раздел FIP)
- **preloader.bin** — прелоадер (записывается в раздел BL2)
- **squashfs-sysupgrade.itb** — постоянная прошивка

### Этап 4: Установка kmod-mtd-rw
- Определение пакетного менеджера (`apk` или `opkg`)
- Установка пакета `kmod-mtd-rw`
- Загрузка модуля ядра `insmod mtd-rw i_want_a_brick=1`

### Этап 5: Запись загрузчика
- Запись `preloader.bin` в раздел `bl2`
- Запись `bl31-uboot.fip` в раздел `fip`

### Этап 6: Установка прошивки
- Запуск `sysupgrade -n` (без сохранения настроек)
- Автоматическая перезагрузка в новую прошивку

## ⚙️ Параметры скрипта

### Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `-v VERSION`, `--version VERSION` | Использовать указанную версию OpenWRT (например: `-v 24.10.0`) |
| `-y`, `--yes` | Неинтерактивный режим — пропустить все запросы подтверждения |

### Конфигурация по умолчанию

| Параметр | Значение |
|----------|----------|
| Версия по умолчанию (fallback) | 25.12.5 |
| Целевая архитектура | mediatek/filogic |
| Модель устройства | netcore_n60-pro |
| Рабочая директория | /tmp/tmp |
| IP-адрес роутера | 192.168.1.1 |

### Автоопределение версии

При запуске без `-v` скрипт:
1. Скачивает список релизов с `https://downloads.openwrt.org/releases/`
2. Отбирает стабильные версии (X.Y.Z) с поддержкой `mediatek/filogic`
3. Показывает топ-5 и позволяет выбрать номером или Enter (самая новая)
4. При недоступности интернета — использует версию по умолчанию

## ⚠️ Важные замечания

- 🔴 **Не прерывайте процесс прошивки** — это может привести к кирпичу роутера
- 💾 **Сделайте резервную копию** перед прошивкой ([02-BACKUP-MTD.md](02-BACKUP-MTD.md))
- 🔌 **Обеспечьте стабильное питание** — используйте ИБП при возможности
- 🌐 **Требуется доступ в интернет** для скачивания образов и установки kmod-mtd-rw
- 💻 **Требуется ~50 МБ свободного места** в `/tmp`

## ❓ Часто задаваемые вопросы

**Q: Как прошить конкретную версию OpenWRT?**
A: Используйте флаг `-v`: `./netis-nx62-update-fw-on-router.sh -v 24.10.0`

**Q: Как запустить скрипт без интерактивных запросов?**
A: Используйте флаг `-y`: `./netis-nx62-update-fw-on-router.sh -y`

**Q: Что делать если скрипт не может скачать файлы?**
A: Проверьте доступ в интернет с роутера: `ping -c1 8.8.8.8`. При отсутствии интернета скрипт использует версию по умолчанию, но скачивание образов всё равно потребует сеть.

**Q: Скрипт выдаёт ошибку SSL?**
A: Скрипт использует `--no-check-certificate` для обхода проблем с сертификатами.

**Q: Можно ли прошить без интернета?**
A: Нет, этот скрипт требует интернет. Для прошивки без интернета используйте скрипт с ПК ([04-FLASH-OPENWRT.md](04-FLASH-OPENWRT.md))

**Q: Что делать если прошивка не удалась?**
A: Попробуйте восстановить через TFTP с ПК (см. [04-FLASH-OPENWRT.md](04-FLASH-OPENWRT.md))

**Q: Почему не форматируется UBI?**
A: `sysupgrade` автоматически обрабатывает форматирование UBI. Ручное форматирование не требуется.
